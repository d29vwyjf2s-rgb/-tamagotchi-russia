# Тамагочи — Россия

Готовый офлайн Android-проект на русском языке в духе карманных виртуальных питомцев 90-х. Дизайн и графика оригинальные.

Возможности: кормление, игра, уборка, лечение, сон, показатели питомца, день/ночь, мини-игра, локальное сохранение. Интернет не требуется.

Открыть в Android Studio → Sync Project → Run. Для APK: `./gradlew assembleDebug`.
